# Contributing to MOVIPA

Thank you for your interest in contributing to MOVIPA!

## Code of Conduct

All contributors must follow our Code of Conduct. Please be respectful and professional in all interactions.

## How to Contribute

### Reporting Bugs
1. Check existing issues first
2. Provide clear description with reproduction steps
3. Include environment details (browser, OS, wallet)
4. Attach screenshots or error logs if relevant

### Suggesting Features
1. Search for existing feature requests
2. Clearly describe the use case
3. Explain the expected behavior
4. Provide examples if possible

### Submitting Pull Requests
Since this is a proprietary project, we have limited external contributions.

For bug fixes:
1. Fork the repository
2. Create a feature branch: `git checkout -b fix/issue-name`
3. Make minimal, focused changes
4. Test thoroughly
5. Submit a PR with clear description

## Development Guidelines

### Code Style
- Follow TypeScript/React conventions
- Use meaningful variable names
- Add comments for complex logic
- Keep functions focused and testable

### Testing
- Test on multiple browsers (Chrome, Firefox, Safari)
- Test on Sepolia testnet
- Verify gas costs are reasonable
- Test with multiple wallet types

### Security
- Never commit private keys or environment variables
- Review security implications of changes
- Report security issues privately to maintainers
- Don't include sensitive configuration

## What We're Looking For

### High Priority
- Bug fixes with clear reproduction steps
- Performance improvements
- Security vulnerability reports
- Documentation improvements

### Lower Priority  
- New features (limited as project is proprietary)
- Style/cosmetic changes
- Refactoring without clear benefit

## What We Won't Accept

- Code that exposes backend architecture details
- Changes that include API keys, contract addresses, or credentials
- Features that compete with core proprietary logic
- Contributions that violate the Proprietary License

## Questions?

Please open an issue or contact the maintainers with questions about the contribution process.
